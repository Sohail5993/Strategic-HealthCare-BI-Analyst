# assets/

This folder is for exported schema diagram images (PNG/SVG), matching the pattern used in `chronic-disease-care-gap-prediction/assets`.

The ER diagrams are already defined as Mermaid code blocks directly in the project's main `README.md` — GitHub renders these natively, so no image export is required for them to display correctly on the repo page.

If you'd like static image versions as well (e.g. for reuse in a slide deck or the LinkedIn-facing write-up), the easiest path is:

1. Open https://mermaid.live
2. Paste in either `erDiagram` block from `README.md`
3. Export as PNG or SVG
4. Save here as `ecommerce_schema.png` and `healthcare_schema.png`
